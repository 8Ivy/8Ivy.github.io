# Yuanlinxi Li — Academic Website

Personal academic website for Yuanlinxi Li (Ivy), a PhD candidate at the Future Design School, Harbin Institute of Technology, Shenzhen.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. The site is deployed automatically to [8ivy.github.io](https://8ivy.github.io/) from the `main` branch.

## Local development

```bash
bundle install
npm ci
bundle exec jekyll serve
```

## Content

- `_pages/about.md` — homepage and research profile
- `_projects/` — research themes
- `_bibliography/papers.bib` — publications
- `_data/cv.yml` — web CV
- `_news/` — selected updates
